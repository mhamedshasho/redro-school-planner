# Redro School Planner

مخطط دراسي عربي صُمّم للاستخدام باللمس على الهاتف، مع حفظ تلقائي محلي.

## الميزات
- واجهة هاتف أولاً وأزرار كبيرة مناسبة للمس.
- تعديل الجدول والخانات وحجم الأيام والحصص.
- قوالب مرئية للمواد: العلوم، الرياضيات، العربية، الإنجليزية، الفرنسية، التاريخ، الجغرافيا، التربية الدينية، المعلوماتية، الرياضة، الفيزياء والكيمياء.
- إضافة صورة من الهاتف لكل خانة، وتحريك موضعها وتكبيرها أو تصغيرها.
- ألوان منفصلة لكل خانة، مع لون مستقل لعناوين الجدول.
- حفظ تلقائي على الجهاز، ومعاينة أفقية، وتصدير PNG والطباعة إلى PDF.
- تطبيق Android بصيغة APK.
