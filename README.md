# Redro School Planner

صانع برنامج أسبوعي مدرسي عربي، متوافق مع الهاتف والكمبيوتر.

## الميزات
- تعديل اسم الطالب والعنوان.
- إضافة وحذف الصفوف والأعمدة.
- تعديل الخانات مباشرة.
- اختيار لون الجدول.
- حفظ تلقائي في المتصفح.
- طباعة وحفظ PDF من نافذة الطباعة.
- تصدير PNG.
- واجهة متجاوبة للهاتف والكمبيوتر.
- تطبيق Android بصيغة APK.
